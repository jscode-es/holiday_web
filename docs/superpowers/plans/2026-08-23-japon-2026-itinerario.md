# Japón 2026 Itinerario Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Next.js web app that digitizes the Japón 2026 trip itinerary (20 days, 27 sep–16 oct 2026) as an editable calendar, list itinerary, route map, accommodations directory, and budget/checklist panel, backed by a local SQLite database seeded from `docs/japon-2026-viaje.md`.

**Architecture:** Next.js 16 App Router with Server Components for reads and Server Actions for writes, a Drizzle ORM schema over `better-sqlite3` as the single source of truth, shadcn/ui primitives for all UI, and `react-leaflet` + OpenStreetMap tiles (no API key) for the map. No auth, no deployment, no automated test suite — this is a single-user local tool.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind v4, shadcn/ui, Drizzle ORM, better-sqlite3, react-leaflet, leaflet, date-fns, tsx (seed script runner).

**Spec:** [docs/superpowers/specs/2026-08-23-japon-2026-itinerario-design.md](../specs/2026-08-23-japon-2026-itinerario-design.md)

## Global Constraints

- No automated test suite (per spec) — every task is verified with `npm run lint`, `npx tsc --noEmit`, and (from Task 6 onward) a manual check against `npm run dev`, not with unit tests.
- Local-only app: no deployment, no authentication, no multi-device sync.
- Free/no-API-key services only: OpenStreetMap tiles, no geocoding API — coordinates are hand-entered constants in seed data.
- Next.js 16 specifics confirmed against `node_modules/next/dist/docs`: `params`/`searchParams` page props are `Promise`s and must be `await`ed; Server Actions live in files with a top-level `'use server'` directive and are called directly from Client Components (not only via `<form action>`); `next/dynamic` with `ssr: false` is only allowed inside a Client Component, never in a Server Component.
- Path alias `@/*` maps to the repo root (`tsconfig.json`), e.g. `@/db/schema`, `@/lib/queries/days`, `@/components/nav`.
- All currency values are stored as plain numbers with a separate `currency` field (`'EUR' | 'JPY'`) — never mix currencies in one sum.
- No react-hook-form/zod: forms are plain `<form>` elements read via `FormData` in client components, calling imported Server Actions directly. This avoids an extra dependency the spec didn't ask for.

- [ ] **Step 1: Write the schema**

```ts
import { sqliteTable, integer, text, real } from 'drizzle-orm/sqlite-core';

export const days = sqliteTable('days', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  date: text('date').notNull(),
  dayNumber: integer('day_number').notNull(),
  title: text('title').notNull(),
  summary: text('summary'),
});

export const activities = sqliteTable('activities', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  dayId: integer('day_id')
    .notNull()
    .references(() => days.id, { onDelete: 'cascade' }),
  time: text('time'),
  type: text('type', {
    enum: ['transport', 'place', 'event', 'comida', 'nota', 'aviso', 'hotel'],
  }).notNull(),
  title: text('title').notNull(),
  description: text('description'),
  status: text('status', { enum: ['programado', 'confirmado', 'pendiente'] }),
  cost: real('cost'),
  currency: text('currency', { enum: ['EUR', 'JPY'] }),
  durationMin: integer('duration_min'),
  origin: text('origin'),
  destination: text('destination'),
  originLat: real('origin_lat'),
  originLng: real('origin_lng'),
  destLat: real('dest_lat'),
  destLng: real('dest_lng'),
});

export const accommodations = sqliteTable('accommodations', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  name: text('name').notNull(),
  checkIn: text('check_in').notNull(),
  checkOut: text('check_out').notNull(),
  nights: integer('nights'),
  cost: real('cost'),
  currency: text('currency', { enum: ['EUR', 'JPY'] }),
  status: text('status', {
    enum: ['programado', 'confirmado', 'pendiente'],
  }).notNull(),
  address: text('address'),
  lat: real('lat'),
  lng: real('lng'),
  notes: text('notes'),
});

export const checklistItems = sqliteTable('checklist_items', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  label: text('label').notNull(),
  done: integer('done', { mode: 'boolean' }).notNull().default(false),
});
```

- [ ] **Step 3: Transcribe the remaining days (3–20)**

For every remaining `## Día N` section in `docs/japon-2026-viaje.md`, add one `ActivitySeed` entry per `###` sub-heading of that day, appended to the `activitySeeds` array before the closing `];`, following these exact mapping rules:

| Markdown pattern | `type` |
|---|---|
| `### HH:MM · Transporte — ...` | `'transport'` |
| `### HH:MM · Lugar — ...` | `'place'` |
| `### HH:MM · Evento — ...` | `'event'` |
| `### HH:MM · Comida — ...` | `'comida'` |
| `### HH:MM · Nota — ...` / `### HH:MM · Aviso — ...` | `'nota'` / `'aviso'` (match the word used) |
| `### Hotel — ...` | `'hotel'`, `time: null` |

Field mapping:
- `title`: the heading text after the `—` (drop the leading `HH:MM ·  Categoría — ` prefix), and drop a trailing `· PROGRAMADO`/`· CONFIRMADO`/`· PENDIENTE` marker from the title into `status` instead.
- `time`: the `HH:MM` from the heading, or `null` for `Hotel` headings.
- `description`: the paragraph text under the heading (join multi-line prose into one string; bullet lists become a single string with `; `-separated items).
- `status`: `'programado'` if the heading or body says PROGRAMADO, `'confirmado'` if CONFIRMADO, `'pendiente'` if PENDIENTE or the body says "Alojamiento pendiente" / "Entrada todavía no comprada" / similar; otherwise `null`.
- `cost` / `currency`: from a `**Coste:**` line if present (`2.479,75 €` → `cost: 2479.75, currency: 'EUR'`; `¥21.800` → `cost: 21800, currency: 'JPY'`); otherwise both `null`.
- `durationMin`: from a `**Duración:**` line, converted to minutes (e.g. `19h 30m` → `1170`); otherwise `null`.
- `origin` / `destination`: from `**Origen:**` / `**Destino:**` lines when present, else `null`.
- `originLat`/`originLng`/`destLat`/`destLng`: only for `type: 'transport'` and `type: 'place'`/`'event'`/`'hotel'` entries that name a real place — use approximate coordinates for the named city/station (e.g. Beppu ≈ `33.2846, 131.4914`; Matsuyama ≈ `33.8392, 132.7657`; Takamatsu ≈ `34.3401, 134.0466`; Naoshima ≈ `34.4606, 133.9975`; Kurashiki ≈ `34.5847, 133.7720`; Okayama ≈ `34.6551, 133.9195`; Osaka ≈ `34.6937, 135.5023`; Nagoya ≈ `35.1815, 136.9066`; Magome ≈ `35.5236, 137.5661`; Tsumago ≈ `35.5589, 137.5786`; Hakone-Yumoto ≈ `35.2323, 139.1069`; Tokyo Station ≈ `35.6812, 139.7671`; Kamakura ≈ `35.3193, 139.5466`; Urayasu/DisneySea ≈ `35.6267, 139.8853`; Haneda T3 ≈ `35.5494, 139.7798`); for `transport` entries put the origin city's coordinates in `originLat`/`originLng` and the destination city's in `destLat`/`destLng`; for `place`/`event`/`hotel` entries put the single location in `destLat`/`destLng` and leave `originLat`/`originLng` null. If a day's activity has no identifiable real-world point (e.g. a generic "Nota" about waking up early), leave all four coordinate fields `null`.
- Use the `BLANK` spread for any entry that has no cost/duration/origin/destination/coordinates, then override only the fields that apply, exactly as Day 2's entries do above.

```ts
export type BudgetSummary = {
  registeredEUR: number;
  registeredJPY: number;
  pendingCount: number;
};

export type PendingItem = { id: string; title: string; source: 'activity' | 'accommodation' };

export async function getBudgetSummary(): Promise<BudgetSummary> {
  const acts = await db.select().from(activities);
  const stays = await db.select().from(accommodations);

  let registeredEUR = 0;
  let registeredJPY = 0;
  let pendingCount = 0;

  for (const row of [...acts, ...stays]) {
    if (row.cost != null && row.currency === 'EUR') registeredEUR += row.cost;
    if (row.cost != null && row.currency === 'JPY') registeredJPY += row.cost;
    if (row.status === 'pendiente') pendingCount += 1;
  }

  return { registeredEUR, registeredJPY, pendingCount };
}

    ...stays.filter((s) => s.status === 'pendiente').map((s) => ({ id: `accommodation-${s.id}`, title: s.name, source: 'accommodation' as const })),
```

```tsx
export function RouteMap({ markers, routes }: { markers: MapMarker[]; routes: MapRoute[] }) {
```

```tsx
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';
import { Checklist } from '@/components/budget/checklist';

export default async function PresupuestoPage() {
  const [summary, pending, checklist] = await Promise.all([
    getBudgetSummary(),
    getPendingItems(),
    getChecklistItems(),
  ]);

  return (
    <div className="space-y-8 p-6">
      <h1 className="text-2xl font-semibold">Presupuesto</h1>

      <div className="grid gap-4 sm:grid-cols-3">
        <Card>
          <CardHeader>
            <CardTitle className="text-sm text-muted-foreground">Registrado (EUR)</CardTitle>
          </CardHeader>
          <CardContent className="text-2xl font-semibold">{summary.registeredEUR.toFixed(2)} €</CardContent>
        </Card>
        <Card>
          <CardHeader>
            <CardTitle className="text-sm text-muted-foreground">Registrado (JPY)</CardTitle>
          </CardHeader>
          <CardContent className="text-2xl font-semibold">¥{summary.registeredJPY.toFixed(0)}</CardContent>
        </Card>
        <Card>
          <CardHeader>
            <CardTitle className="text-sm text-muted-foreground">Pendientes</CardTitle>
          </CardHeader>
          <CardContent className="text-2xl font-semibold">{summary.pendingCount}</CardContent>
        </Card>
      </div>

      <div className="space-y-2">
        <h2 className="text-lg font-semibold">Elementos pendientes</h2>
        <ul className="space-y-1 text-sm text-muted-foreground">
          {pending.map((item) => (
            <li key={item.id}>{item.title}</li>
          ))}
        </ul>
      </div>

      <div className="space-y-2">
        <h2 className="text-lg font-semibold">Checklist antes de salir</h2>
        <Checklist items={checklist} />
      </div>
    </div>
  );
}
```
